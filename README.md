# From-Stray-to-Stay-Leveraging-Data-to-Improve-Pet-Adoption-and-Shelter-Efficiency
Analysis of Austin Animal Center intake and outcome data (2020–2025), exploring trends, animal characteristics, repeat intakes, and operational insights using SQL and Tableau to support data-driven decision making.

Team 02: Angela Liou, Allen Chiu, Bill Odiase, Shon Shaju and Yuyang Zhai
